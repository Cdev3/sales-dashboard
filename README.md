# 📊 Sales Analysis Dashboard

## 🚀 Overview

This project presents an interactive **Sales Analysis Dashboard** built using Microsoft Excel.
It analyzes sales data to uncover trends, top-performing products, and regional performance insights.
---
## 📊 Dashboard Features

* **Monthly Sales Trend**
  Visual representation of sales performance over time

* **Top 5 Products**
  Identifies highest revenue-generating products

* **Region Distribution**
  Shows contribution of each region to overall sales

* **Interactive Filters (Slicers)**
  Filter dashboard by:

  * Region
  * Category
---
## 🛠️ Tools Used

* Microsoft Excel
  * Pivot Tables
  * Pivot Charts
  * Slicers
